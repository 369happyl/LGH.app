O que é JavaScript?

JavaScript é uma linguagem de programação muito utilizada para adicionar interatividade e comportamento às páginas da Web.

HTML cria a estrutura, CSS cuida da aparência e JavaScript adiciona lógica e interatividade.

1. Variáveis

Variáveis armazenam informações que podem ser utilizadas pelo programa. 

let nome = "Jãozin";
let idade = 13;

2. Funções

Uma função é um bloco de código criado para realizar uma determinada tarefa. 

function dizerOla() {
    alert("Olá!");
}

3. Condições

O JavaScript pode tomar decisões utilizando if e else. 

let idade = 18;

if (idade >= 18) {
    console.log("Maior de idade");
} else {
    console.log("Menor de idade");
}

4. Manipulando o HTML

JavaScript consegue acessar e modificar elementos HTML através do DOM. 

document.querySelector("#texto")
    .textContent = "Texto alterado!";

Este texto pode ser alterado.

5. Eventos

Eventos são ações que acontecem na página, como clicar em um botão ou pressionar uma tecla.

  • click → quando algo é clicado
  • input → quando um campo muda
  • keydown → quando uma tecla é pressionada
  • mouseover → quando o mouse passa sobre algo

🧠 Desafio

O que acontecerá quando esse código for executado? 

let numero = 10;

if (numero > 5) {
    console.log("O número é maior que 5");
}
